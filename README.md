## Run locally
Open `index.html` in a browser. Images are loaded from Unsplash and Google Fonts require an internet connection.

## Deploy with GitHub Pages
1. Create a new GitHub repository for this project.
2. Upload all four files (`index.html`, `style.css`, `script.js`, `README.md`) to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for the Pages URL to appear. Open it to confirm the site loads.

## Note
This is a student activity project. Dashboard values and Smart City statistics are sample/demo data. The Smart City request form displays a local demo confirmation and does not send data to a server.
